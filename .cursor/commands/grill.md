# grill

Before writing a single file change or plan:
1. Relentlessly interview me regarding the intended feature, bug fix, or modification.
2. Ask 3-4 highly specific, logical, or architectural questions per turn.
3. Force me to walk down separate branches of the design tree, resolving dependencies and edge cases one by one.
4. Do not output implementation code or build a final asset until we explicitly reach a shared, bulletproof design concept.
